# Reference

`docs/reference/` は current contract や workflow の実行入口ではないが、背景説明や履歴確認のために保持する reference-only 文書を置く領域です。

## Reference Sets
- [ORCA order alignment reference](orca-order-alignment/README.md)
- [Repository history / discovery](repository-history/README.md)

## Rules
- reference は current source of truth を置き換えない
- `docs/contracts/`、`docs/runbooks/`、`docs/managerdocs/`、`web-client/notes/` と役割が重なる内容は置かない
- enduring reference は要約せず、参照リンクに寄せる
