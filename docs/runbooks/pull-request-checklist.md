# PR チェックリスト（テンプレート）

このテンプレートは `server-modernized` のコードと文書の乖離を防ぐための最低要件である。PR 作成時に本文へ貼り付け、各項目を埋めること。

## 1. 対象作業
- [ ] 対応対象の契約文書を特定した。
- [ ] 契約変更がある場合、コード変更前に文書へ目標仕様を反映した。

## 2. コード変更
- [ ] 仕様どおりにコードを更新した。
- [ ] 不要になった互換分岐 / 旧キー / TODO を削除した。
- [ ] 例外時に raw host / URL / secret / stack trace を API 応答へ露出しないことを確認した。

## 3. 文書変更
- [ ] `README.md` のリンクを更新した、または更新不要であることを確認した。
- [ ] 関連契約文書を更新した。
- [ ] `config/server-modernized.env.sample` を更新した、または更新不要であることを確認した。
- [ ] リリース検証手順を更新した、または更新不要であることを確認した。

## 4. テスト
- [ ] 既存テストを更新した。
- [ ] 新規の正常系テストを追加した。
- [ ] 新規の異常系テストを追加した。
- [ ] `mvn clean verify` を実行した。
- [ ] Failsafe の統合テストが 1 件以上実行されたことを確認した。

## 5. エビデンス
- [ ] 実行したコマンドを PR に記載した。
- [ ] 主要レスポンス例またはログ例を PR に記載した。
- [ ] 変更したファイル一覧を PR に記載した。
- [ ] 未完了事項がある場合は、残課題と影響範囲を PR に明記した。

## 6. 禁止事項確認
- [ ] `src/main` に runtime DDL を追加していない。
- [ ] `ServerConfigurationResolver` 以外へ新規の `System.getenv` / `System.getProperty` / `ConfigProvider.getConfig()` を追加していない。
- [ ] 生成物 `target/` や WAR をレビュー対象へ含めていない。
