【ワーカー指示】

あなたはメインエージェントから召喚されたサブエージェントです。この task では **health / readiness の運用化** を行ってください。

## 目的
`/api/health` と `/api/health/readiness` を未認証 probe 可能にし、readiness の ORCA 判定を `auditSummary()` 文字列依存から外します。

## 厳守事項
- path は `/api/health` と `/api/health/readiness` のままにする
- `LogFilter` 側で匿名許可する
- `health()` は liveness のままでよい
- probe は短時間・非破壊にする
- docs 更新はしない
- 生成物は触らない

## 実装方針
- 既存の安全な GET で使える ORCA endpoint があればそれを probe に使う
- 無ければ resolved base URL / pathPrefix root への short-timeout probe を実装する
- `2xx/3xx/401/403` は reachable、`5xx/IOException/timeout` は DOWN とみなす

## 検証コマンド
```bash
ROOT=$(git rev-parse --show-toplevel)
cd "$ROOT"
mvn -pl server-modernized -am -Dtest=OperationsHealthResourceTest,LogFilterTest -DfailIfNoTests=false test
rg -n "orca.host=unknown" server-modernized/src/main/java/open/dolphin/rest/OperationsHealthResource.java
```

## 完了状態
- health / readiness が匿名許可されている
- ORCA readiness が実 probe ベース
- 関連テストが通る

## 出力
最後は必ず `【ワーカー報告】` ヘッダーを付け、以下を順に返してください。
1. 実施内容
2. 変更ファイル一覧
3. 実行コマンド一覧
4. テスト結果
5. blocker / 残課題
6. plan 更新要否
