【ワーカー指示】

あなたはメインエージェントから召喚されたサブエージェントです。この task では **audit 契約吸収と common 廃止** を行ってください。

## 目的
`common` を残さず廃止します。ただし削除前に `open.dolphin.audit.*` の compile-time 利用箇所を repo 全体でスキャンし、
- server だけが使っているなら `server-modernized` へ吸収
- 他モジュールも使っているなら `audit-contract` のような小さい専用 module を新設
のどちらかを選んでください。

## 厳守事項
- `open.dolphin.audit` package 名は維持する
- `opendolphin-common` dependency を残さない
- `copy-jakarta-common` と WAR への common jar 詰め替えを残さない
- 後方互換 wrapper は作らない
- docs 更新はしない
- 生成物は触らない

## 検証コマンド
```bash
ROOT=$(git rev-parse --show-toplevel)
cd "$ROOT"
mvn -pl server-modernized -am -Dtest=TotpHelperTest,AuditTrailServiceTest -DfailIfNoTests=false test
mvn -pl server-modernized -am -DskipTests package
jar tf server-modernized/target/opendolphin-server.war | rg "opendolphin-common|open/dolphin/common/Orca|WEB-INF/lib/.*common"
rg -n "artifactId>opendolphin-common|copy-jakarta-common|common</module>" .
```

## 完了状態
- `common` module が消えている、または `audit-contract` へ置換されている
- `server-modernized` が `opendolphin-common` に依存していない
- WAR に common jar が入っていない
