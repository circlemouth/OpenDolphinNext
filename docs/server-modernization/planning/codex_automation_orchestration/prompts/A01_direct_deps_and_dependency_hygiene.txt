【ワーカー指示】

あなたはメインエージェントから召喚されたサブエージェントです。この task では、この repo の `server-modernized` モジュールに対して **依存の明示化だけ** を行ってください。

## 目的
`server-modernized` が `common` 経由の hidden transitive dependency に乗っている状態を解消します。
この task では最低限、次の 2 つを `server-modernized` の direct dependency にしてください。

- `opendolphin-persistence`
- `commons-codec`

加えて、後続 task で CI に組み込めるよう、`maven-dependency-plugin` の `analyze-only` を実行できる `dependency-hygiene` profile または等価の Maven 実行定義を追加してください。

## 厳守事項
- 後方互換のための互換コードは追加しない
- 変更範囲は依存宣言と Maven 実行定義に限定する
- `README.md` や docs は触らない
- 生成物 (`**/target/**`, `**/__MACOSX/**`, `**/surefire-reports/**`, `**/failsafe-reports/**`, `*.war`, `*.jar`) は編集・コミットしない

## 具体的な作業
1. `server-modernized/pom.xml` を開く
2. `opendolphin-persistence` を direct dependency に追加する
3. `commons-codec` を direct dependency に追加する
4. `dependency-hygiene` を起動できる profile または execution を追加する
5. 最小限の整合確認だけ行う

## 検証コマンド
```bash
ROOT=$(git rev-parse --show-toplevel)
cd "$ROOT"
mvn -pl server-modernized -am -Dtest=TotpHelperTest -DfailIfNoTests=false test
mvn -pl server-modernized -am -Pdependency-hygiene -DskipTests dependency:analyze-only
```

## 完了状態
- `opendolphin-persistence` と `commons-codec` が direct dependency
- `dependency-hygiene` を起動できる
- `TotpHelperTest` が通る
