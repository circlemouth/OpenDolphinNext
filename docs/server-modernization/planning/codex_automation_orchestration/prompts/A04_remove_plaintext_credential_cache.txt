【ワーカー指示】

あなたはメインエージェントから召喚されたサブエージェントです。この task では **平文 credential cache とその管理 API の削除** を行ってください。

## 目的
header credential cache の平文 password 保持と、その可視化 / clear API を本番コードから丸ごと削除します。

## 厳守事項
- `UserCache` と `AdminSecurityResource` は削除する
- 互換 endpoint や deprecated wrapper は作らない
- docs 更新はしない
- 生成物は触らない

## 対象
- `UserCache.java`
- `AdminSecurityResource.java`
- `OpenDolphinRestApplication.java`
- `UserCacheTest.java`
- `AdminSecurityResourceTest.java`
- `WebXmlEndpointExposureTest.java`

## 検証コマンド
```bash
ROOT=$(git rev-parse --show-toplevel)
cd "$ROOT"
rg -n "UserCache|header-credentials/cache|HEADER_CREDENTIAL_CACHE" server-modernized/src/main server-modernized/src/test
mvn -pl server-modernized -am -Dtest=WebXmlEndpointExposureTest -DfailIfNoTests=false test
```

## 完了状態
- `UserCache` 実装が消えている
- `AdminSecurityResource` が消えている
- 公開 resource 登録から外れている
- 関連テストが通る
