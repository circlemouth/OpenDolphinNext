# 変更方針
## injection
- `admin/adminCode/adminMemo/speed` は local-only
- local save/fetch は可
- send payload / XML には出さない
- `admin -> adminCode required` の server logic を除去する
- help/tests を同期する

## med
- usage 系は local-only
- send row を作らない
- server resource は usageCode を必須扱いしない
- editor restore bug を直す

## RP-level claim comment
- `StoredRpMeta.claimComments` を保持し、source bundle keep 条件に入れる
- `85/831` note が link marker に化けないようにする
- unknown family reject は維持する

## otherOrder
- legacy `800..890` / `8...|18...` を削除する
- explicit local-only contract に置き換える
- classCode は validation 根拠に使わない。型都合で必要なら shared local-only sentinel を使う
- rowRole は `main/comment` のみ
- send-block は維持

## surgery
- allow=`500/501/502/510`, block=`520/540/541/542`
- `501/502` standalone を許可
- canonical rowRole は `main/material/comment`
- `material` を `main` や `auxiliary` に揺らさない
- validation / persistence / fetch / display の全部で同じ resolver を使う

## testOrder
- allow=`600/601/602/603/610`
- reject=`640/643` と allowlist 外全体
- save/send/server が同じ helper/table を見る

## SoT / canonicalization
- client の `orderRpRequirements.ts` 独自 canonicalization を catalog 委譲へ寄せる
- server の charge/radiology canonicalization map を catalog 委譲へ寄せる
- stale helper は削除または本実装へ寄せる

## docs / tests / notes
- injection help を local-only 契約へ直す
- `orderBundleOrcaSupport.test.tsx` を同期
- `orderSendSmoke.test.ts` の旧注射 usage row 期待を削除
- `chartsActionBar.orca-send.test.tsx` の stale treatment bodyPart expectation を current reject 契約へ直す
- notes の文言を current class map に合わせる
