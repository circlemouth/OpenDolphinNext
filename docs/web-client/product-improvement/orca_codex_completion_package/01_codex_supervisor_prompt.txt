# 変更方針
## A. Source-of-truth
- entity canonicalization は client/server とも 1 箇所へ寄せる
- charge / radiology class canonicalization の独自 map を廃止し catalog 委譲へ寄せる
- input-set metadata の broad fallback を削除する
- radiology の UI label `放射線` を `画像診断` に統一する
- comment family 判定の regex 直書きを helper 委譲へ寄せる

## B. First-class prescription save
- bundle path だけでなく first-class prescription save でも unknown structured family reject を入れる
- `genericChangeAllowed` を source helper round-trip で保持する
- RP-level structured claim comment note を source bundle / mutation operation / fetch で保持する

## C. Family contract closure
- treatment: exact class + class-aware grammar + bodyPart reject + no resurrection
- surgery: `500/501/502/510` allow, `520/540/541/542` block, `501/502` standalone、rowRole 単一化
- test: `600/601/602/603/610` allow, `640/643` reject を save/send/server 共通 grammar にする
- physiology: import-only + local save/fetch 可 + send-block + `classCode=600` exact
- bacteria: local-only + local save/fetch 可 + send-block + `830/842` のみ round-trip
- radiology: exact allowlist + `710..724` block + bodyPart は `700` のみ + no resurrection
- otherOrder: legacy ORCA shape を捨て、1 つの explicit local-only contract に統一

## D. Docs / tests / dead code
- injection help text を current wire contract に合わせる
- stale tests を current contract へ更新する
- radiology note wording を exact class map に合わせる
- 使わない helper / duplicate logic / dead code を削除する

# 実行中の必須チェック
- 「catalog にはあるが production path が見ていない」状態を残さない
- 「send は止まるが save で通る」や「write で reject だが read で resurrect」状態を残さない
- client と server で rule table / alias / family logic / rowRole semantics をずらさない
- broad rule を残したまま helper だけ追加しない
- docs/help/tests を後回しにしない
