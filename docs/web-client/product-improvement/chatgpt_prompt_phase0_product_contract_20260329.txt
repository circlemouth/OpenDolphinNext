## 作成してほしい成果物
以下を markdown でまとめてください。

### 1. auth 例外 copy matrix
最低限以下を含めること。
- credentials failure
- factor2 required
- factor2 invalid
- factor2 session missing
- factor2 session expired
- too many requests / lockout
- authentication_failed
- header auth mismatch / security-failure 相当

列:
- trigger
- user-facing message
- tone (`success/info/warn/error`)
- CTA
- 画面遷移
- notes

### 2. redirect reason taxonomy
対象:
- logout
- session expiry
- unauthorized
- forbidden
- switch account
- invalid / empty returnTo
- deep link scrub fallback

列:
- reason key
- where it appears
- user-visible label
- detail text
- CTA
- replace/push 方針

### 3. lost-context surface matrix
対象 surface:
- Charts
- Patients
- Mobile Images
- Administration（必要なら note で限定）

列:
- surface
- lost-context 条件
- fallback
- user-visible explanation
- CTA
- unresolved unknown

### 4. feedback copy catalog v1
分類:
- auth
- state-loss
- fetch-failure
- save-failure
- logout partial success
- feature disabled

各項目に
- canonical copy
- tone
- CTA の有無
- raw detail を出さない理由
を入れること。

### 5. a11y minimum memo
最低限:
- 色だけに依存しない
- live region をどこで使うか
- focus をどこで移すか
- keyboard 操作で最低限守ること
- narrow layout で崩してはいけない順序

### 6. unresolved unknown list
`06_open_unknowns_and_evidence_gaps.md` と整合させて、
- 何が unknown か
- なぜ今は決めないか
- 誰が証拠を取るべきか
- 実装に進む条件
を整理すること。

## 制約
- patient context を URL / localStorage / sessionStorage に保存する案は禁止
- auth-sensitive transition の `replace` を前提に考える
- `DocumentTimeline` を通常主面に戻さない
- admin の source of truth は `/api/admin/config`
- raw backend/internal detail を user-facing copy に使わない
- repo-external の required checks / secrets / deploy はスコープ外
