## Threat model
- Misuse case 1: UI 表示語や自由文字列を `Disease_Class` などの ORCA code として送信し、ORCA 側の病名属性を誤登録する。
  - Mitigation: server-side allowlist にない値は validation error とし、ORCA transport へ到達させない。
- Misuse case 2: レセプト表示期間に範囲外値を混入し、請求表示の意味を壊す。
  - Mitigation: `Disease_Receipt_Print_Period` は blank / `None` / 2桁コードだけに限定する。
- Misuse case 3: `Base_Month` を DTO に持っていても XML へ出ず、送信内容と operation hash / review の前提がずれる。
  - Mitigation: diseasev3 XML に `Base_Month` を明示出力し、既存の `yyyyMM` validation と合わせて固定した。
