## Threat Model

- Assets: period PDF export, chart revision export hashes, prescription/ORCA provenance summaries, date range and patient filter.
- Trust boundary: request query filters are untrusted; facility and chart/reporting payloads are server-derived.
- Attack surface: cross-facility period export, excessive date range PDF generation, PDF-specific projection drift that omits provenance or includes raw ORCA/credential/PHI.

## Misuse Cases

1. A user attempts to include another facility's chart in a period PDF by guessing `patientId`.
   - Countermeasure: period query filters by server-side session facility and each chart PDF reuses `exportChartReportingPayload(chartId, facilityId)`.
2. A user requests an excessive date range to generate an unbounded PDF.
   - Countermeasure: period PDF calls the same period export path with required ISO dates and 366-day maximum.
3. A raw ORCA body, Authorization header, Cookie, or PHI-bearing summary is embedded through a PDF-only path.
   - Countermeasure: period PDF reuses each chart's sanitized JSON/reporting payload and never accepts client-provided reporting payload.
