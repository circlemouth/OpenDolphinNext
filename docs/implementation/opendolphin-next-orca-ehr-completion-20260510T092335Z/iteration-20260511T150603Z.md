## Threat Model

- Assets: audit event coverage matrix, owner evidence, release blocker status, reviewer packet summaries, and audit emission proof.
- Trust boundary: inventory rows may cite owners, tests, fixed status, and sanitized evidence only; they must not include PHI, raw ORCA payloads, credentials, browser artifacts, or raw network captures.

## Misuse Cases

1. A required audit label remains in the contract but loses implementation owner/evidence tracking.
2. A worker marks a live ORCA audit label complete using mock, stale RUN_ID, or candidate discovery proposal evidence.
3. A reviewer packet treats a UI log, local console message, or prose-only note as authoritative audit coverage.
4. Audit inventory text captures raw patient detail, insurance detail, credential, raw ORCA body, HAR, trace, video, screenshot, or raw network evidence.
