## Misuse Cases And Mitigations

- Misuse case: a dry-run billing/report summary is presented as live ORCA execution or paid/receipt authority. Mitigation: packet validation requires `liveTrialOrca.executed=false`; docs state the summary is gate evidence only.
- Misuse case: the packet generator copies broad billing/report evidence with raw ORCA bodies or browser artifacts. Mitigation: only one sanitized JSON file is allowlisted and copied.
- Misuse case: closeout JSON embeds raw patient ID, invoice number, `Data_Id`, `Medical_Uid`, credential headers, request XML, HAR, or raw network references. Mitigation: key-level and text-level validation fails packet creation/validation.
- Misuse case: client-provided storage key/digest is treated as report binary authority. Mitigation: validator requires the server-generated storage key/digest evidence boundary and forbidden evidence classes include client-provided storage metadata.
