## Trust Boundary
- WebORCA Trial is an external authority for patient, insurance, and appointment read-only responses.
- The browser and QA artifact path are not authority for mutation approval.
- Candidate discovery alone cannot authorize Phase 3 mutation; exact selected-candidate preflight is still required.

## Attack Surface
- Credential, Cookie, Authorization, CSRF, raw ORCA body, or patient detail leakage through stdout, tracked docs, or QA artifacts.
- Accidental mutation route execution while probing read-only readiness.
- Reuse of candidate discovery or stale artifact path as if it were exact preflight approval.

## Misuse Cases
1. An operator runs candidate discovery and treats official patient/insurance acceptance as approval for mutation.
2. A hidden browser request attempts patient, visit, acceptance, disease, medical, billing, or temporary reconcile mutation during read-only evidence collection.
3. A stale or non-exact preflight artifact is supplied to the Phase 3 handoff.
4. A live Trial run emits raw identifiers, insurance detail, credentials, HAR, trace, video, screenshot, or raw ORCA body into tracked output.
