# Iteration 20260510T185931Z

## Checklist Item

- Section 17: 重要警告を初期非表示にする UI を削除または変更する。

## Scope

Charts action bar の compact header collapsed 状態で、`fallbackUsed=true` の暫定データ警告が `詳細` disclosure 内だけに隠れないようにする。

## Threats / Controls

- Misuse case 1: 利用者が compact header の `詳細` を開かず、fallback データのまま ORCA送信・会計送信・印刷へ進んだと誤認する。
  - Control: `fallbackUsed=true` では collapsed header 直下に `role="alert"` の visible warning を表示し、再取得を明示する。
- Misuse case 2: debug/meta pill の `fallbackUsed` だけでは利用者向けの次アクションが分からない。
  - Control: alert copy を「ORCA送信・会計送信・印刷前に最新データを再取得」に固定する。
- Misuse case 3: 警告表示に trace / request / patient details / ORCA raw body を混ぜ、tracked evidence や UI に漏らす。
  - Control: 表示は固定文言のみとし、患者氏名、保険詳細、trace、request、raw ORCA body、credential は扱わない。

## Changes

- `ChartsActionBar` の compact collapsed header で `fallbackUsed` 警告を `details` 外の alert として初期表示する。
- `chartsActionBar.test.tsx` に、fallback warning が `details` 内へ閉じ込められていないことを固定する test を追加した。
