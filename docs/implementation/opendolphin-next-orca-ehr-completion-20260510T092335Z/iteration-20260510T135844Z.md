## Selected Checklist Item

- 9.3 病名DTO: UI表示値とORCA送信コードを分離する。
- 9.5 病名UI: 病名送信前確認で病名属性とORCA送信コードを表示する。

## Scope

`DiagnosisEditPanel` の詳細入力で、病名保険区分、病名カテゴリ、病名区分、レセプト表示期間、退院証明を ORCA 仕様コードとして選択・入力できるようにした。確認ダイアログでは表示語と実際に送るコードを並べ、未指定は `送信しない` と明示する。

## Threat Model

- Client-provided display text or free text could be sent as ORCA diseasev3 codes.
- Out-of-range `Disease_Receipt_Print_Period` could reach the official bridge.
- Confirmation UI could hide which ORCA codes are sent, causing unsafe operator assumptions.

## Controls

- Detailed controls use fixed select options for allowlisted code fields.
- `Disease_Receipt_Print_Period` is validated as `None` or `00` through `99` before mutation.
- Confirmation shows both Japanese display labels and the exact ORCA code string.
- Server-side validation remains the final authority; this client validation is an early UX guard.
