## Checklist Item

- Section 17: ORCA送信成功を診療録確定と同義に扱う UI 文言、ORCA送信失敗時に登録済み/反映済みと表示する文言、重要警告を初期非表示にする UI を削除または変更する。

## Threat Model

- Misuse case 1: 患者登録・更新の write accepted を、ORCA正本再取得済みの完了状態として誤認する。
- Misuse case 2: ORCA既存患者取込で canonical 再取得失敗時にも「反映結果確認済み」と読める文言が出て、古い患者キャッシュを現在正本として扱う。
- Misuse case 3: missing master / fallback 表示で「反映停止」とだけ出て、患者情報の同期確認が停止している事実と復旧導線が弱くなる。

## Changes

- Patients の登録・更新・ORCA既存患者取込 UI で、完了状態を `同期確認済`、未確認状態を `同期確認失敗`、停止状態を `同期停止` に統一した。
- write accepted without readback の表示を「ORCA正本の再取得による同期確認が完了していません」に変更し、登録済み/反映済みと誤認させない表現にした。
- missing master / fallback の患者識別帯ラベルを `同期停止注意` / `同期停止` に変更し、ORCA正本確認が停止中であることを明示した。
- PatientsPage focused tests の期待値を更新し、未確認時に完了 copy が表示されないことを維持した。
