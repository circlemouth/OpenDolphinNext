## Assets / trust boundary / attack surface
- Assets: JSON export revision list, event list, sanitized summaries, snapshot manifest summary, `exportHash`.
- Trust boundary: API output is server-generated, but may be stored or transferred outside the server after export.
- Attack surface: export consumer storage, manual edits to exported JSON, accidental omission of event rows, unsafe summary injection.

## Misuse cases
- An exported JSON file loses a `CANCELLED` or `AMENDED` event before archive review.
- A revision summary or snapshot summary is edited after export.
- Unsafe raw ORCA / credential text is included in hash material before redaction and then leaks through verification artifacts.

## Implementation
- Added `ChartRevisionExportResponse.exportHash`.
- `ChartRevisionExportService` computes SHA-256 over a deterministic server-side material built from redacted/allowlisted revisions, events, and snapshot manifest summaries.
- Added regression coverage that `exportHash` exists and changes when sanitized event payload changes.
- Kept CSV fixed-column output compatible; CSV continues to use formula neutralization and summary redaction.
