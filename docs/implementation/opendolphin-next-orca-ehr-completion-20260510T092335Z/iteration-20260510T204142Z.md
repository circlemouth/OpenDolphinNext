## Misuse Cases

1. `medicalmodv2` の送達確認を利用者が診療録確定または会計済みと誤認し、収納確認や再照合を省略する。
2. `ORCA_UNKNOWN` / `ORCA_FAILED` / warning を details/disclosure 内へ戻し、初期表示で要確認状態を見落とす。
3. ORCA送信失敗や canonical 再取得未完了を visible copy で `登録済み` / `反映済み` / `完了扱い` と表示し、未確定 state を正本化したように見せる。
