## Threat Model

- Trust boundary: only allowlist sanitized subsets may cross from local closeout artifacts into reviewer packet evidence.
- Attack surface: report text, command logs, QA JSON/log summaries, runtime blocker evidence, and copied packet metadata.

## Misuse Cases

1. A closeout report links `chart-export-raw.json` or `raw-chart-export.csv`, turning raw chart export into reviewer evidence.
2. A report references `report-binary.pdf` or `report-body.xml`, exposing raw ORCA report/PDF-like payloads instead of hash/count metadata.
3. Patient image or attachment download artifacts such as `patient-image-download.png` or `attachment-download.zip` are copied into packet evidence.
4. Raw object storage location evidence such as `storage-uri.txt` is included and bypasses the protected export authorization matrix.
