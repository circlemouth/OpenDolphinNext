## Threat model
- Misuse case 1: `合併症` などの表示語を `Sub_Disease_Class` として送信し、ORCA 側で誤登録または validation failure を起こす。
  - Mitigation: select option value を ORCA code に限定し、確認ダイアログで表示語と code を分離表示する。
- Misuse case 2: レセプト表示や保険病名が利用者に見えないまま暗黙送信される。
  - Mitigation: controls と確認ダイアログに表示値を出し、送信 code も同じ確認面に表示する。
- Misuse case 3: client-side controls を authority と誤認し、保険組合せや患者文脈を client 値で確定する。
  - Mitigation: 今回の controls は payload hint に限定し、server-side allowlist と server-derived encounter context が最終 authority である契約を維持する。
