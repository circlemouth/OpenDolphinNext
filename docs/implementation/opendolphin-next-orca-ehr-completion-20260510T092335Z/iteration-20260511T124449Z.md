## Misuse Cases

1. A preflight accidentally calls `patientmodv2` or acceptance mutation and still emits `blockedRequestCount=0`. Mitigation: `buildReadonlyMutationPolicy` scans recorded request paths and rejects preflight with `readonly_mutation_attempt_blocked`.
2. Blocked request evidence stores patient ID, insurance detail, token, or request body fields. Mitigation: blocked evidence only contains route template, method, and fixed reason.
3. A preflight with a local billing send or temporary medical reconcile request is used as Phase 3 handoff. Mitigation: `acceptedForPhase3Attempt` now requires `mutationPolicy.blockedRequestCount === 0`, and summary evaluation returns `readonly_mutation_attempt_blocked`.
