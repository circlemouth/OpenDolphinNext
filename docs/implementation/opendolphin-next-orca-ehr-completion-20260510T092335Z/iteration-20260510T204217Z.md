## Assets / Trust Boundary / Attack Surface

- Assets: ORCA credentials, Cookies, Authorization headers, JSESSIONID, CSRF tokens, raw ORCA XML/body, patient name/address fields, insurance number fields, audit evidence, browser bundle, test results, Playwright output, test snapshots.
- Trust boundary: browser/test harness/runtime output is untrusted until sanitized; reviewer packets may only include allowlisted sanitized subsets.
- Attack surface: failing browser/e2e runs, Playwright diagnostic artifacts, test snapshots, built bundle output, copied audit/log snippets, reviewer evidence extraction.

## Misuse Cases

1. A failing Playwright run writes `network.har`, trace/video/screenshot, or `error-context.md`, and the file is accidentally reviewed or packaged.
2. A test snapshot captures `Authorization: Basic ...`, Cookie/JSESSIONID/CSRF, or ORCA credential env values from a diagnostic response.
3. A sanitized evidence summary regresses and includes raw ORCA body/XML, patient name/address fields, or insurance number fields.
4. A web bundle accidentally contains ORCA credential-bearing variables or raw proxy output after a local experiment.
