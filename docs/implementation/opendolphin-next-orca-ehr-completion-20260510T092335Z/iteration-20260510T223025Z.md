## Misuse Cases
- A clinician cannot learn why `ORCA 送信` is unavailable because native disabled prevents interaction and only a title carries the reason.
- A patient/encounter context failure opens the critical confirmation modal anyway, creating false confidence that the operation is ready.
- A missing ORCA master or incomplete official visit row is silently patched by client UI state and reaches transport.

- Routed clicks with precheck failures into the existing fail-closed `handleAction('send')` path, which shows a warning banner and records blocked audit/telemetry, without opening the confirmation modal or calling transport.
- Updated focused tests for missing master, missing encounter context, and incomplete official visit row.
