## Scope
- `medicalmodv2` response に `operationStatus` と `needsUserReview` を追加した。
- `Medical_Warning_Info` がある場合は `Api_Result` 正常でも `ORCA_WARNING` / `needsUserReview=true` として返す。
- Web client は `ORCA_WARNING` / `needsUserReview` / `medicalWarnings` を成功通知へ丸めず、要確認の warning UI として扱う。
- `Api_Result` 正常かつ warning の場合、送達状態は `送信済` として保持し、会計確定は `incomeinfv2` 照合まで未判定のままにする。

## Threats And Controls
- Threat: ORCA警告を成功扱いにして補正が見落とされる。
  - Control: `operationStatus=ORCA_WARNING` と `needsUserReview=true` を response / UI 判定 / audit details に通す。
- Threat: 業務拒否や通信失敗が同じ失敗表示に潰れて再送判断を誤る。
  - Control: `ORCA_REJECTED`、`NETWORK_FAILED`、`UNKNOWN` の固定 status へ分類する。
- Threat: raw ORCA body や接続先情報が証跡に残る。
  - Control: response / docs / tests は固定 field と sanitized summary のみを扱い、raw XML・資格情報・患者詳細・保険詳細を追加しない。
