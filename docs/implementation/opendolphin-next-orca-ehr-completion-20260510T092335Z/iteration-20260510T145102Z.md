# Iteration 20260510T145102Z

## Checklist Item

- 16.3: ORCA送信失敗、`UNKNOWN`, `NEEDS_REVIEW` の一覧画面を作る。

## Changes

- `GET /api/local/encounters/orca-transmissions/review` を追加し、review 対象の billing ORCA transmission を server-side facility scope で列挙できるようにした。
- 一覧対象は server 固定で `ORCA_UNKNOWN`, `ORCA_FAILED`, `CORRECTION_REQUIRED` に限定し、client から facility、patient detail、状態 enum、ORCA URL、raw XML、voucher / sequential / insurance combination を受け付けない。
- `limit` は server 側で 1..100 に clamp する。
- response DTO は sanitized metadata のみを返し、`Medical_Uid` は値ではなく presence flag として返す。
- public route inventory と ORCA connection contract、workstream checklist を更新した。

## Threats And Controls

- Threat: client が facility や状態 enum を改ざんして他施設または成功済み transmission を列挙する。
  - Control: facility は `requireFacilityId(request)` から解決し、状態は SQL の固定 allowlist だけにした。
- Threat: 一覧 API が患者詳細、保険詳細、raw ORCA body、ORCA credential を漏らす。
  - Control: response DTO は encounter/schedule/patient identifiers、fixed state、result code/message、timestamps、request/trace id に限定し、raw response JSON と `Medical_Uid` 値を返さない。
- Threat: 大量取得で運用画面や DB を圧迫する。
  - Control: `limit` を server-side で 1..100 に clamp する。
