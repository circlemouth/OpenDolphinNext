## Assets / Trust Boundary / Attack Surface

- Assets: `chart_document.current_revision_id`, current revision status, chart revision JSON export hash material.
- Trust boundary: API callers do not provide current revision status; it is derived from server-side revision rows.
- Attack surface: current revision status confusion, pointer/status tampering, omitted revision rows, unsafe summary payloads.

## Misuse Cases

- A consumer treats an old `FINAL` revision as current after an `AMENDED` revision exists.
- A corrupted current pointer changes without an obvious status signal in the export envelope.
- A revision row is omitted while `currentRevisionId` remains present in the export envelope.

## Implementation

- `ChartRevisionExportService` derives the status from the exported current revision row and includes it in canonical hash material.
- Existing fail-closed guard still rejects a `currentRevisionId` that is absent from the revision list.
