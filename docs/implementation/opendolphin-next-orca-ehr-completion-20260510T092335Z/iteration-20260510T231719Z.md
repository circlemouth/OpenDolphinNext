- Client omits or tampers with `prescriptionLocation` / `medicationRoute` to hide院内外 or category before candidate preparation.

- Client attempts to set input actor/owner/role/facility through payload instead of authenticated server context.
- JSON-only item persistence hides unresolved structured fields from ORCA candidate review.
