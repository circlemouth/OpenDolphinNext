# Iteration 20260510T155357Z

## Checklist Item

- 16.3: ORCA側で会計済みの場合は再送を原則禁止し、管理者確認フローにする。

## Scope

- `tmedicalgetv2` read-only 再照合の `Medical_Mode` / `Medical_Mode2` から、再送を止めるべき ORCA 側状態を server-side に判定する。
- Web client は server の `resendBlocked` をそのまま表示し、client 側で解除判定を作らない。

## Threats And Controls

- Client-provided authority: 再照合 request は transmission ID だけを送り、patient / facility / insurance / voucher / sequential / `Medical_Uid` / raw XML / URL は受け付けない既存境界を維持した。
- Duplicate resend after ORCA-side billing: `Medical_Mode` または `Medical_Mode2` が空でなく `0` 以外の場合は fail-closed に `resendBlocked=true` とし、自動再送・成功扱いを禁止する。
- Sensitive evidence leakage: response、UI、audit は `Medical_Uid` の存在有無と sanitized block reason だけを扱い、`Medical_Uid` 値、保険組合せ、raw ORCA body、資格情報、患者詳細を保存・表示しない。
