## Threat Model

- Assets: exact selected-candidate read-only preflight summary, artifact hash, input identity hash, Phase 3 approved mutation handoff.
- Trust boundary: local artifact paths and environment variables such as `QA_READONLY_PREFLIGHT_SUMMARY` are operator-controlled input and cannot authorize ORCA mutation by path presence alone.
- Attack surface: discovery proposal artifacts, accept/fullflow mutation artifacts, network/raw browser diagnostics, copied old summaries, and old RUN_ID evidence can be confused with exact preflight evidence.
- Misuse cases:
  - Candidate discovery summary is supplied as if it were exact selected-candidate preflight.
  - `acceptmodv2`, fullflow, or network artifact paths are supplied with an otherwise valid hash.
  - A copied summary from a non-canonical or old artifact location is supplied to bypass the exact preflight run boundary.

## Implementation

- Error text reports a fixed reason/classification and does not echo the local artifact path.
