1. A closeout includes billing/report result JSON but command log omits the result command, making the evidence chain unauditable.
2. A command log records `--live` or trace/HAR/video/screenshot/raw network capture flags and the packet still ships sanitized-looking JSON.
3. A live billing/report profile is treated as executed without current dry-run, manual approval handoff, operator template, and result record command evidence.
