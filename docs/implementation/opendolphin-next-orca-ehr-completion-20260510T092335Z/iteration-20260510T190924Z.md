# Iteration 20260510T190924Z

## Checklist Item

- Section 17: 重要警告を初期非表示にする UI を削除または変更する。

## Scope

Charts の患者ヘッダーで `missingMaster` / `fallbackUsed` が pill 表示だけに留まり、利用者が ORCA正本確認不能の次アクションを読み落とす経路を塞ぐ。

## Threats / Controls

- Misuse case 1: `ORCA参照不足` / `暫定参照` の pill だけでは、ORCA送信・会計送信前に再取得が必要だと判断できない。
  - Control: 患者ヘッダーの supporting area に `role="alert"` の固定 warning を表示し、再取得要求を明示する。
- Misuse case 2: 患者ヘッダーの補助情報や details を開かない利用者が、暫定参照のまま作業を継続する。
  - Control: alert は `details` 外に配置し、初期表示で読める状態にする。
- Misuse case 3: alert に患者氏名、住所、電話番号、保険詳細、trace、request ID、raw ORCA body を含める。
  - Control: alert は固定文言と再取得アクションだけに限定し、患者詳細や ORCA 詳細は追加しない。

## Changes

- `ChartsPatientSummaryBar` に `missingMaster` / `fallbackUsed` 用の visible alert を追加した。
- alert の視認性を `charts-patient-summary__source-alert` で固定した。
- `ChartsPatientSummaryBar.test.tsx` に、alert が `details` 外に表示される regression test を追加した。
