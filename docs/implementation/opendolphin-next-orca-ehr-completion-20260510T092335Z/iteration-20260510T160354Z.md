# Iteration 20260510T160354Z

## Checklist Item

- 16.4: ORCA障害時は UI に「ORCA連携停止中」を表示しつつ、診療録正本閲覧を可能にする。

## Scope

- App shell の ORCA readiness 表示を、system admin 専用ではなく warning/error 時だけ全ロールに出す。
- 正常時の `ORCA: readiness OK` は引き続き非表示にし、管理画面/運用監視を詳細確認の正本にする。

## Threats And Controls

- Information disclosure: 表示は `/api/health/readiness` の sanitized `checks.orca.status` だけを使い、URL、host、credential、raw error、stack trace を表示しない。
- Role confusion: non-admin でも障害認知に必要な `ORCA連携停止中` は見せるが、管理画面ボタンや接続詳細は出さない。
- Unsafe client authority: App shell は readiness を表示するだけで、ORCA 接続先や送信可否の権威判定を client 側に持たせない。

## Changes

- `AppRouter` の ORCA readiness polling を全ロールで実行し、warning/error のみ compact status として表示。
- ORCA `DOWN` / readiness fetch failure の visible label を `ORCA連携停止中` に統一。
- AppRouter navigation test に non-admin ORCA DOWN 表示と秘密情報非表示の regression を追加。
- UI current contract と EHR checklist を更新。
