## Queue
- Worker B B-05a: chart revision CSV export bridge for checklist 14.

## Assets / trust boundary / attack surface
- Assets: chart revision/export response, `chart_revision_event` provenance, CSV report output.
- Trust boundary: HTTP session facility is authoritative; chart/event free text and summary JSON are untrusted even after persistence.
- Attack surface: guessed `chartId` cross-facility export, raw ORCA/credential text pasted into event reason/title/summary, spreadsheet formula execution when CSV is opened.

## Misuse cases
- User from a different facility requests `/api/charts/{chartId}/revisions/export.csv`.
- Event reason contains `Authorization`, `Cookie`, raw XML, or SOAP body copied from an ORCA trace.
- Event reason/title/summary starts with `=`, `+`, `-`, `@`, or tab to trigger formula execution in spreadsheet software.

## Implementation
- Added `GET /api/charts/{chartId}/revisions/export.csv`.
- CSV export reuses `ChartRevisionExportService.exportChart`, so facility scoping, redaction, and summary allowlist stay aligned with JSON export.
- CSV rows include fixed provenance columns for revision rows and event rows: identifiers, event type, reason, actor, hash, and summary.
- CSV cell output quotes values and neutralizes spreadsheet formula prefixes.
