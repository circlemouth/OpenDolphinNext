## Scope

- DB write path または監査ログ書き込みが degraded の場合の read-only mode を `docs/runbooks/orca-outage-recovery.md` に固定する。
- backup restore 後に local ORCA送信状態だけで成功昇格しない復旧手順を固定する。
- ORCA connection contract と release validation gate に同じ境界を反映する。

## Threat Model

- DB 書き込み不能時に ORCA 送信だけが成功し、診療録・送信ログ・監査ログが欠落する。
- backup restore 後の古い local `ORCA_SENT` / `ORCA_CONFIRMED` を現在の ORCA 正本として誤表示する。
- `ORCA_UNKNOWN` / `ORCA_FAILED` の送信を、restore 後に ORCA 再取得なしで自動再送して二重算定する。
- DB degraded と ORCA outage を混同し、ORCA が `UP` なら送信可能と誤判断する。
