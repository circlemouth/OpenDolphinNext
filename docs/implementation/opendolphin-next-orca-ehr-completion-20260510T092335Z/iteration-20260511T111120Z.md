## Assets / Trust Boundary / Attack Surface

- Assets: chart revision export payload, prescription order/revision/event history, export CSV, canonical `exportHash`, document-integrity contract.
- Trust boundary: client input is not authority. Export uses server-side chart facility plus DB-persisted `prescription_order.chart_revision_id` linkage. Prescription summary JSON is treated as untrusted output material and projected through an allowlist.

2. Prescription event summaries contain `patientName`, `rawOrcaBody`, or insurance details; export must drop allowlist-excluded keys.
3. Prescription event type/content hash/summary changes after export; canonical `exportHash` must change.
