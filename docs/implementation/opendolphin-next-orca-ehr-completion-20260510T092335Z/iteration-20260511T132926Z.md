## Threat Model

- Assets: ORCA Trial credentials, WebORCA read responses, candidate/preflight summaries, runtime smoke artifacts, local runtime config, and reviewer-facing release evidence.
- Trust boundary: Trial secrets may enter only as process environment; tracked docs and reviewer evidence may contain only set/unset state, hashes, counts, categories, and sanitized verdicts.
- Attack surface: setup logs, Flyway/API health logs, Playwright harness artifacts, network/request summaries, command transcripts, worker board summaries, and release packet inputs.

## Misuse Cases

1. A live Trial run prints or commits the Basic credential, cookie, CSRF token, `Authorization`, `JSESSIONID`, or raw ORCA body.
2. A failed candidate run is incorrectly promoted to mutation-ready and executes `acceptmodv2` without exact read-only preflight acceptance.
3. Untracked browser artifacts such as HAR, screenshots, traces, videos, raw request XML, or raw network dumps are copied into reviewer evidence.
4. A local runtime setup failure is misclassified as an ORCA blocker instead of a local environment/setup issue.
