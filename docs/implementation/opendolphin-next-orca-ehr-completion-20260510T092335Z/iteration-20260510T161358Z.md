- Credential leakage: runbook は readiness の sanitized status / reason code だけを使い、ORCA URL、host、credential、raw ORCA body を証跡に残さない。

- Duplicate billing resend: `ORCA_UNKNOWN` は即再送せず、`tmedicalgetv2` read-only 再照合と `resendBlocked` 判定を必須にする。
