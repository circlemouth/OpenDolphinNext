## Assets And Trust Boundary

- Assets: `qa/billing-report-live-result/result.sanitized.json`, reviewer submission packet `closeout-packet/`, ORCA billing cache and report snapshot evidence.
- Trust boundary: reviewer packet tooling treats operator result JSON as untrusted closeout input. It copies only the allowlisted sanitized result record and validates hash-only ORCA cache/snapshot evidence before packaging.
- Attack surface: raw identifier key names, raw artifact references, storage key/digest leakage, upload failure or blockers being packaged as accepted evidence, local absolute path leakage.

## Implementation

- Added `qa/billing-report-live-result/result.sanitized.json` to required closeout and packet files.
- Added reviewer packet validation for `qa-orca-billing-report-live-result` records.
- Result validation requires ready handoff summary hash, allowed `operatorOutcome`, `rawSensitiveFieldsExcluded=true`, ORCA income cache hash/row evidence, report snapshot hash/status evidence, server-generated storage key/digest presence, and no blockers.
- `UPLOAD_FAILED` / `EXPIRED` / raw storage key or digest fields / raw patient, invoice, `Data_Id`, `Medical_Uid`, credential, HAR, raw network, and request XML references are rejected.
- Updated reviewer packet and release-validation runbooks, checklist, worker board, and this iteration doc.

## Misuse Cases And Mitigations

- Misuse case: packet includes raw `Data_Id`, invoice, patient identifier, storage key, storage digest, credential, or request XML. Mitigation: key-name scanner and raw artifact text scan reject the packet before generation or validation succeeds.
- Misuse case: failed object upload is packaged as successful billing/report evidence. Mitigation: reviewer packet accepts only `NOT_UPLOADED`, `RETENTION_BLOCKED`, or `UPLOADED` with server-generated storage boundary and no blockers.
- Misuse case: operator result is packaged without a ready manual handoff. Mitigation: result validation requires `handoff.readyForManualLiveExecution=true` and a sha256 handoff summary hash.
- Misuse case: result evidence is interpreted as local billing/payment/report body authority. Mitigation: runbooks state the evidence is ORCA-derived cache/snapshot evidence only.
