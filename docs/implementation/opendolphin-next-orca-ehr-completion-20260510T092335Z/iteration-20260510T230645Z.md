# Worker A Iteration 20260510T230645Z

## Scope

- Queue: A-05 route guard hardening for absent local patient CRUD and absent patient delete.
- Checklist: 3.1, 6, 13.
- Assets: public JAX-RS route inventory, web.xml API exposure, patient create/update/delete surface.
- Trust boundary: server public route registration is the enforcement boundary; UI hiding, docs wording, and legacy archived strings are not authority.
- Attack surface: reintroducing the legacy local patient mutation route, adding local patient create/update aliases, adding patient delete routes, or exposing a patient CRUD shim outside official patientmodv2.

## Misuse Cases

- The legacy local patient mutation route is restored and lets clients create/update `d_patient` as a local source of truth.
- A `DELETE /api/orca/official/patient*` or `DELETE /api/local/patient*` route is added and users can remove ORCA patient authority from OpenDolphinNext.
- A local or admin alias bypasses `/api/orca/official/patientmodv2/outpatient/*` and weakens canonical re-fetch requirements.
- Route docs and web.xml drift so route inventory no longer matches the official/master/local taxonomy.

## Implementation

- Added server route inventory assertions that allow only official `patientgetv2`, official `patientmodv2` create/update, and local patient search for patient create/update/delete-adjacent surfaces.
- Added fail-closed negative assertions for `DELETE /api/orca/official/patient*`, `DELETE /api/local/patient*`, the legacy local patient mutation route, and local patient PUT/PATCH.
- Updated route taxonomy to make patient delete non-implementation a guarded contract.
- Marked checklist items for OpenDolphinNext-only patient create/update API removal and patient delete non-implementation complete.
- Updated Worker A board entry.
