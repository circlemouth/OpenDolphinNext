## Pre-implementation model

- Assets: runtime-ready smoke closeout summary, candidate discovery summary, exact selected-candidate preflight gate, ORCA Trial runtime credential boundary, and reviewer-safe evidence policy.
- Trust boundary: the browser QA harness is diagnostic; server-side ORCA readiness and read-only probes are not mutation authorization; timeout/blocker summaries cannot replace exact selected-candidate preflight.
- Attack surface: blocker writers crashing before evidence, timeout races overwriting the intended `candidate_discovery_timeout` summary, raw network artifacts being retained, and accidental progression to mutation from read-only partial evidence.

## Misuse cases

1. `runtime-ready-smoke` hits no official row and crashes while summarizing `null`, leaving only terminal stderr and no machine-readable blocker.
2. Candidate discovery timeout closes the browser while the main flow is still running, causing a generic request-error summary to overwrite the timeout blocker.
3. A candidate discovery timeout or rejected proposal is treated as Phase 3 authorization without exact selected-candidate readonly preflight.
4. Raw network/browser artifacts from failed candidate discovery are retained and later copied into tracked evidence or a reviewer packet.
