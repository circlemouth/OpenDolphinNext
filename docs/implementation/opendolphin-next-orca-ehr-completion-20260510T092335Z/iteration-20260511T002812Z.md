# Worker A Iteration 20260511T002812Z

## Scope

- Queue: A-08 acceptance cancellation cache event and encounter workflow boundary guard.
- Checklist: 3.3, 6, 13.
- Assets: ORCA `acceptlstv2` inventory, `orca_acceptance_cache` cancellation event, `encounter_projection` / future `encounter_workflow_state`.
- Trust boundary: ORCA acceptance cache is ORCA-derived display/reconciliation state. Encounter workflow is OpenDolphinNext authority and must not be deleted or cancelled by cache inventory absence alone.
- Attack surface: malicious or incorrect ORCA inventory delta forcing encounter deletion/cancellation, cross-facility workflow mutation, stale cache promoted as workflow authority, patient or insurance detail leaking through cancellation evidence.

## Misuse Cases

- A missing row in `acceptlstv2` causes an in-progress encounter to be deleted.
- A cancellation cache event from another facility changes the current facility's encounter workflow.
- A stale local acceptance cache is treated as proof that ORCA sending is safe.
- Cancellation evidence stores patient detail, insurance detail, raw ORCA body, or credential-like data.
