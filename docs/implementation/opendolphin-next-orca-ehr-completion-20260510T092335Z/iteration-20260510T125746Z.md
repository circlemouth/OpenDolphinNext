## Threat model
- Misuse case 1: client が別医師コードを payload に混入し、ORCA diseasev3 を誤った担当医で送信する。
  - Mitigation: server-derived `physicianCode` と完全一致しない payload を transport 前に拒否し、一致時も server-derived 値で上書きする。
- Misuse case 2: client が top-level 保険組合せを改ざんし、病名登録を別保険文脈へ紐付ける。
  - Mitigation: top-level と entry-level の保険組合せを server-derived context で照合し、送信 XML は server-derived 値で生成する。
- Misuse case 3: client が malformed `baseMonth` を送り、ORCA mirror / mutation 周辺の基準月解釈を曖昧にする。
  - Mitigation: `yyyyMM` 以外は validation error とし、ORCA transport へ到達させない。
