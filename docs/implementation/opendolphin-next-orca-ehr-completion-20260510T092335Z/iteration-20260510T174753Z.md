## Checklist Item

- Section 17: ORCA送信成功を診療録確定と同義に扱う UI 文言、ORCA送信失敗時に登録済み/反映済みと表示する文言、重要警告を初期非表示にする UI を削除または変更する。

## Threat Model

- Misuse case 1: `medicalmodv2` の送信応答だけを利用者が会計済みまたは診療録確定と誤認し、収納照合や要確認 recovery を省略する。
- Misuse case 2: 同日別 encounter の positive send cache が画面に出て、別受付の送信状態を現在の診療録状態として扱う。
- Misuse case 3: 送信待ち/処理中の表現を「反映済み」に近い言葉で表示し、未確定状態のまま会計へ進む。

## Changes

- `OrcaSummary` の `ORCA送信: 成功` を `ORCA送信応答: 送達確認` に変更した。
- `Transmission / medical-mod-v2` の説明へ、会計済み判定だけでなく診療録確定とも別概念であることを明記した。
- `DocumentTimeline` の送信待ち/queue pending の次アクションから「反映」表現を外し、送信結果/キュー状態の確認に寄せた。
- `resolveOrcaSendStatus` の delivered/ack label を `成功` から `送達確認` に変更した。
- focused semantics test に、旧 `ORCA送信: 成功` が表示されず `送達確認` が表示されることを追加した。
