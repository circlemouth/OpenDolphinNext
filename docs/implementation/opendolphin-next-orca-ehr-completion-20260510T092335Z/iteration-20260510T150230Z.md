## Threats And Controls

- Threat: client が facility や状態 enum を改ざんして別施設または任意状態の transmission を表示する。
  - Control: Web client は `limit` だけを送り、facility と対象状態は server endpoint の authority に委ねる。
- Threat: recovery 一覧が idempotency key、request ID、trace ID、raw ORCA body、保険組合せ、伝票番号、連番を画面や client model に露出する。
  - Control: API adapter で client model から秘密系・運用内部識別子を落とし、UI も限定フィールドだけを表示する。
- Threat: Reception に初回会計送信ボタンが復活し、Charts の `診察終了して会計へ送信` と責務が混ざる。
  - Control: review list は表示専用にし、既存テストに初回 `会計送信` direct button が出ないことを追加確認した。
