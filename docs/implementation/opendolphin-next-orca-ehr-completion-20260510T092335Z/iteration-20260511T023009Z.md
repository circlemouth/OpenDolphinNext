## Trust Boundary
- Reconcile context comes from the saved billing snapshot and saved transmission record.
- Request body, fallback timestamps, and client-provided identifiers are not authority.
- Incomplete server snapshot context fails closed before ORCA transport.

## Attack Surface
- Missing `visitDate` causing a fallback to transmission `startedAt`.
- Missing `departmentCode` producing a broad or ambiguous ORCA read.
- Incomplete snapshot context reaching ORCA transport and returning a misleading reconcile summary.
- Raw ORCA body, patient details, insurance details, or credentials entering tracked evidence.

## Misuse Cases
1. A corrupted snapshot without `visitDate` uses transmission time as the ORCA perform date.
2. A corrupted snapshot without `departmentCode` creates a broad `tmedicalgetv2` query.
3. A partial snapshot reaches ORCA transport and is treated as a valid reconcile attempt.
4. A context failure leaks raw ORCA or patient/insurance details into tracked files.

## Implementation
- Temporary medical reconcile payload generation now requires `snapshot.visitDate` and `snapshot.departmentCode`.
- The previous `startedAt` fallback for perform date was removed.
- Empty department is no longer emitted; missing department fails before ORCA transport.
