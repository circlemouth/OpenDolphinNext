## Assets / Trust Boundary / Attack Surface

- Assets: `chart_document.current_revision_id`, chart revision export revision list, export hash material.
- Trust boundary: API callers do not provide current revision authority; export state is resolved from server-side DB rows.
- Attack surface: current pointer drift, omitted revision rows, facility crossover export, unsafe summary/reason payloads.

## Misuse Cases

- A buggy export query omits the current revision while still returning `currentRevisionId`.
- A corrupted `chart_document.current_revision_id` points to a revision outside the exported chain.
- A caller attempts to use another facility's chart id to inspect revision state.
