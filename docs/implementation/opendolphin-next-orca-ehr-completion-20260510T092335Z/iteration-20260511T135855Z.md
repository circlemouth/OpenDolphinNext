## Threat Model

- Assets: ORCA connection settings, deployment secret store state, readiness responses, audit write path, object storage profile, backup/restore evidence, reviewer packet evidence, and rollback records.
- Trust boundary: production operator evidence may record sanitized status, hashes, counts, and stop-condition verdicts only; tracked files must not contain credentials, session tokens, raw ORCA payloads, PHI, browser captures, or raw network artifacts.
- Attack surface: release validation logs, runbook copies, reviewer packets, CI guard fixtures, runtime config summaries, Trial execution notes, and operator handoff docs.

## Misuse Cases

1. A successful Trial read is treated as production readiness even though ORCA credentials, certificate monitoring, audit writes, backup/restore, or rollback checks are missing.
2. A reviewer packet or release evidence bundle copies raw ORCA payloads, credentials, PHI, HAR, trace, video, screenshot, or raw network dumps.
3. A deployment uses an object-storage-free Trial profile or local secret fallback in production.
4. A restore drill promotes restored ORCA-facing state as authoritative without a fresh ORCA read/reconcile.
