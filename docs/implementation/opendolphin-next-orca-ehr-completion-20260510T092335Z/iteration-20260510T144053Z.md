## Threats And Controls

- Threat: ORCA 結果不明を通常成功として表示し、未照合のまま会計待ちへ遷移する。
  - Control: `needsUserReview` / `UNKNOWN` / review state を検出した時点で `contextAlert` を出し、後続の受付状態更新と tab close を停止する。
- Threat: 利用者が結果不明のまま二重送信する。
  - Control: error path へ流し、ActionBar の失敗通知と page-level 要確認で recovery 確認を促す。
- Threat: 送信結果詳細や患者情報が UI / tracked evidence に漏れる。
  - Control: UI 文言は固定文にし、error metadata は runId / traceId / fixed status / ORCA result code-message だけに限定する。
