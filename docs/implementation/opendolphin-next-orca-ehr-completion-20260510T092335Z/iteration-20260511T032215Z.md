## Misuse Cases And Mitigations

- Misuse case: operator runs dry-run, sees planned paths, but does not notice result evidence is not part of the current contract. Mitigation: dry-run JSON lists required closeout and packet files including the result record.
- Misuse case: packet generation proceeds after result evidence is omitted, then an old RUN_ID or out-of-band zip is used to patch the gap. Mitigation: dry-run and generation share source validation and fail on the missing required result file.
- Misuse case: dry-run leaves partial `submission-packet-*` output that could be mistaken for reviewer evidence. Mitigation: focused test asserts dry-run does not create the output directory.
- Misuse case: result evidence includes raw artifact references or upload failure. Mitigation: existing packet validators still run during dry-run source validation.
