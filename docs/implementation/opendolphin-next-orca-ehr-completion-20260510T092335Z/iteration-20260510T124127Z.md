## Threat model
- Misuse case 1: Web client または別 resource が local diagnosis create / update / delete を再利用し、ORCA `diseasev3` の警告・不一致・再取得 semantics を迂回する。
  - Mitigation: service-level mutation methods を削除し、公開 route inventory は `GET /api/local/diagnoses/{*}` のみを固定した。
- Misuse case 2: クライアント提供の patient / facility / disease payload を local DB に直接保存して ORCA 正本と誤表示する。
  - Mitigation: local write entry point を削除し、既存 local-only disease は pending projection の read model に限定した。
- Misuse case 3: 将来の refactor で `/api/local/diagnoses` に unsafe method が混入する。
  - Mitigation: `PublicRouteInventoryContractTest` が `/api/local/diagnoses` の route key を GET のみと検証する。
