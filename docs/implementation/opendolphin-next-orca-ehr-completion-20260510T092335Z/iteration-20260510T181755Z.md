## Threat Model

- Misuse case 1: 既存患者更新が ORCA に受け付けられただけの状態を、ORCA正本の再取得・同期確認済みとして誤認する。
- Misuse case 2: backend 由来の `canonical 再取得` や `完了扱い` などの内部語がそのまま画面へ出て、利用者が業務状態を判断しづらくなる。
- Misuse case 3: 患者取込 recovery で write accepted かつ再取得失敗の状態を、登録済みまたは反映済みとして扱う。

## Changes

- `PatientInfoEditDialog` で backend message に内部同期語が含まれる場合は表示せず、ORCA正本再取得による同期確認の成否を利用者向け文言に正規化した。
- 既存患者更新 dialog の説明を、ORCA正本更新と再取得による同期確認を分けて理解できる表現に変更した。
- `orcaPatientImportRecovery` の `canonical_refetch_failed` 文言を、患者取込は受け付け済みだが ORCA正本の再取得による同期確認は未完了である、という表現へ変更した。
