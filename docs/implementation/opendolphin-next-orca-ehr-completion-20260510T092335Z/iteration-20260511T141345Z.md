## Threat Model

- Assets: chart revision PDF exports, revision/event history, prescription history, ORCA operation/transmission/reconciliation history, snapshot manifest references, export hashes.
- Trust boundary: HTTP request parameters and authenticated session enter `ChartRevisionResource`; facility and export payload are resolved server-side by `ChartRevisionExportService`.
- Attack surface: print endpoints, date range and patient filters, chart ID path parameter, PDF response headers.
- Misuse cases:
  - A caller uses a print route to bypass export redaction and obtain raw ORCA bodies, credentials, or unnecessary PHI.
  - A caller tampers with `patientId`, `fromDate`, `toDate`, or `chartId` to print charts outside the authenticated facility.
  - A caller supplies or influences a client-side reporting payload for inline print output and injects arbitrary nested summary content.
- Controls:
  - Print aliases call the same `exportChartPdf` / `exportChartPeriodPdf` service methods as attachment exports.
  - Facility and date-range validation remain in the shared service path.
  - The only behavior difference is `Content-Disposition: inline`; file names and binary payloads remain service-derived.
