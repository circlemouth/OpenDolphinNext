## Threat model
- Misuse case 1: 確認ダイアログで表示語だけを見せ、実際の ORCA code が利用者に見えないまま送信される。
  - Mitigation: 表示属性と `Main_Disease_Class` / `Disease_SuspectedFlag` を同じ確認面に表示する。
- Misuse case 2: `主病名` などの UI 表示語を payload に混入し、ORCA 側で属性誤登録または validation failure を起こす。
  - Mitigation: UI は `mainDiseaseClass=01` に変換して送信し、前回追加した `mutateOrcaDisease` preflight と server allowlist が二重に検証する。
- Misuse case 3: 別患者・別診療日の病名操作を利用者が見落とす。
  - Mitigation: 確認ダイアログに ORCA患者番号、診療日、診療科、保険組合せを再掲する。
