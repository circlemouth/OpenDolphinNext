## Checklist Item

## Threat Model

- Misuse case 1: `diseasev3` が ORCA に受け付けられたことを、ORCA登録病名一覧へ反映済みの状態として誤認する。
- Misuse case 2: post-mutation mirror が unavailable の状態で、入力病名や local optimistic result を ORCA登録病名として扱う。
- Misuse case 3: 確認 dialog の説明が「画面へ反映」と表現され、ORCA正本再取得結果だけを主一覧へ表示する境界が弱くなる。

## Changes

- `DiagnosisEditPanel` の create/update/delete/削除病名整理 success copy を `ORCA再取得結果で同期確認しました` に変更した。
- post-mutation mirror 未適用時の copy を `ORCA再取得結果を確認中です` に変更し、未確認状態を positive な反映表示にしない。
- ORCA病名操作 confirm dialog の説明を「再取得した結果だけを ORCA登録病名として表示します」に変更した。
- focused test の expected copy を更新した。
