## Assets / Trust Boundary / Attack Surface

- Assets: chart revision JSON export, revision/event provenance counts, canonical `exportHash`.
- Trust boundary: caller-supplied request context is not authority; facility is resolved server-side and export content is built from DB state.
- Attack surface: missing revision/event rows in export, sanitized summary tampering, reason/title payloads containing secrets or raw XML/SOAP.

## Misuse Cases

- A caller attempts facility crossover export by passing another chart id; export remains facility-scoped and fail-closed.
- A compromised or buggy export path omits revision/event rows; `revisionCount` / `eventCount` and hash material expose the record-count mismatch.
- Summary/reason text contains Authorization, Cookie, raw XML, SOAP, patient detail, or allowlist-excluded fields; export projects only sanitized allowlist values.
