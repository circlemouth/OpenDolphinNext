# Iteration 20260510T110944Z

## Scope

- Checklist item: `diseasev3` レスポンスで warning / unmatched を成功扱いに潰さず、`needsUserReview` と `operationStatus` を返す。
- Assets: `/api/orca/official/chart-support/disease-mod-v3`, Charts disease API, ORCA disease mutation audit summary.
- Trust boundary: client payload and ORCA response are untrusted. Facility and encounter context remain server-derived; response detail is normalized to fixed fields only.

## Changes

- `ChartSupportDiseaseModV3Response` に `needsUserReview` と `operationStatus` を追加。
- ORCA warning / unmatch がある場合、business response が ok-like でも `ORCA_WARNING` / `ORCA_UNMATCHED` として user review を要求。
- disease mutation audit summary に `operationStatus`, `needsUserReview`, warning/unmatch counts を追加し、raw XML や ORCA 内部詳細は保存しない。
- Web Charts disease mutation API は review-needed response を plain success にせず、確認が必要な message として返す。

## Misuse Cases

- Client が warning を success として扱い、ORCA 不一致を見落とす。
- ORCA warning message に患者情報や内部詳細が含まれ、API/UI/監査へ露出する。
- Transport failure や parser ambiguity を accepted と誤分類する。
